# Contributing

Obrigado por contribuir com este repositório! Siga estas orientações básicas:

- Abra uma issue antes de começar trabalho maior para alinharmos o escopo.
- Fork e crie uma branch com nome descritivo: `feature/nome-curto` ou `fix/descricao`.
- Faça commits pequenos e com mensagens claras (ex.: `feat: adicionar exemplo de Serial`).
- Envie um Pull Request descrevendo o que foi feito, como testar e quais arquivos foram alterados.
- Mantenha o estilo simples: código legível, nomes claros e comentários quando necessários.
- Execute testes manuais/automáticos (se houver) antes de submeter o PR.

Licença: ao contribuir você concorda em licenciar suas contribuições sob a mesma licença do projeto (MIT).

Contato: reporte dúvidas ou problemas via Issues no repositório.
