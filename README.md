# PRÁTICAS DE ALGORITMOS E PROGRAMAÇÃO

- **Universidade:** Universidade UNA Pouso Alegre
- **Período:** 1º semestre de 2026

## Objetivos (resumido)

- **Raciocínio algorítmico:** desenvolver decomposição de problemas e modelagem IPO (entrada-processamento-saída).
- **Representação de algoritmos:** usar pseudocódigo como formato principal; fluxogramas como suporte visual.
- **Implementação prática:** traduzir algoritmos para VisuALG, C++, e Arduino; construir um projeto integrador com considerações éticas.
